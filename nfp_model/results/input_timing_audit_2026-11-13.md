# NFP Model Input Timing Audit

As of 2026-11-13, the live artifact selects 50 features. **The available records do not certify that all inputs were published by the 8 p.m. Eastern prior-day cutoff for every historical forecast.**

The official calendars confirm release schedules, not the availability of each historical feature vintage. Local audit tables cover some claims, JOLTS, ISM, ADP and CES hours observations, but the available evidence does not provide complete timestamped source documents and consensus snapshots for every feature and month.

The BLS CES strike report is not among the live artifact’s selected features. BLS says it summarizes large strikes during the reference pay period and is normally released the Friday before the Employment Situation; it is preliminary and may be incomplete. It should not be added without archived report vintages and cutoff checks.

See `input_timing_audit_2026-11-13.json` for the 50-feature inventory and evidence assessment. A historical performance comparison should use only rows with source and consensus evidence verified against the forecast cutoff.
